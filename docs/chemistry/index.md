# 初中化学 · 浙教版

## 课程体系

### 🟢 基础核心

| 模块 | 内容 |
|------|------|
| 物质分类 | 纯净物/混合物、单质/化合物/氧化物 |
| 微观构成 | 原子分子离子、前20号元素、化合价、化学式书写 |
| 化学反应 | 四大基本反应、化学方程式配平 |
| 溶液 | 溶质质量分数、溶解度曲线 |
| 酸碱盐 | 酸碱盐通性、金属活动性顺序 |

### 🟡 高频考点

- 必考方程式默写
- 化学方程式计算
- 物质推断
- 物质鉴别与除杂
- 结晶方法
- 离子沉淀特征
- 气体检验套路

### 🔴 拔高要点

- 质量守恒、元素守恒、电荷守恒
- 混合物计算
- 氧化还原初步认知
