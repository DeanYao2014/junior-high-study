# 化学方程式 · 配平与计算

> 星级：⭐⭐⭐⭐ | 浙江中考填空、计算必考

## 书写规则

1. 以客观事实为依据
2. 遵循质量守恒定律
3. 注明反应条件

## 配平方法

### 最小公倍数法
1. 找出左右出现一次且原子数较多的元素
2. 求最小公倍数
3. 确定化学计量数

### 观察法
从最复杂的化学式入手。

## 方程式计算步骤

1. 设未知数
2. 写出化学方程式
3. 找已知量与未知量的关系
4. 列比例式求解
5. 作答

## 典型例题

**例：** 实验室用 10g 碳酸钙与足量盐酸反应，可制得多少克二氧化碳？

**解：** $\text{CaCO}_3 + 2\text{HCl} = \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2 \uparrow$

$$\frac{100}{10} = \frac{44}{x}, \quad x = 4.4\text{g}$$
