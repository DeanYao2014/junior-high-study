# 等高线地形图判读

> 星级：⭐⭐⭐⭐ | 浙江中考地图题必考

## 基本特征

| 特征 | 判读方法 |
|------|----------|
| 等高线密集 | 坡度陡 |
| 等高线稀疏 | 坡度缓 |
| 等高线闭合，内高外低 | 山顶 |
| 等高线向高处凸出 | 山谷 |
| 等高线向低处凸出 | 山脊 |

## 五大地形部位

| 部位 | 特征 |
|------|------|
| 山顶 | 等高线闭合，数值从中心向四周递减 |
| 山谷 | 等高线向海拔高处凸出（易发育河流） |
| 山脊 | 等高线向海拔低处凸出 |
| 鞍部 | 两山顶之间的低洼部位 |
| 陡崖 | 等高线重叠处 |

## 典型例题

**问：** 某登山队沿 AB 线登山，哪一侧更省力？为什么？

**答：** A 侧更省力。因为 A 侧等高线较稀疏，坡度较缓。
