# 欧姆定律 · 电路分析

> 星级：⭐⭐⭐⭐⭐ | 浙江中考电学必考

## 基础公式

$$I = \frac{U}{R}$$

| 物理量 | 符号 | 单位 |
|--------|------|------|
| 电流 | $I$ | 安培 (A) |
| 电压 | $U$ | 伏特 (V) |
| 电阻 | $R$ | 欧姆 (Ω) |

## 串并联规律

| 连接方式 | 电流 | 电压 | 电阻 |
|----------|------|------|------|
| 串联 | $I = I_1 = I_2$ | $U = U_1 + U_2$ | $R = R_1 + R_2$ |
| 并联 | $I = I_1 + I_2$ | $U = U_1 = U_2$ | $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$ |

## 典型例题

**例：** $R_1 = 10\Omega$，$R_2 = 20\Omega$ 串联，电源电压 $U = 6V$。求电路电流。

**解：** $R = R_1 + R_2 = 30\Omega$

$I = \frac{U}{R} = \frac{6}{30} = 0.2A$
