# 记叙文阅读 · 语句赏析

> 星级：⭐⭐⭐⭐ | 浙江中考阅读理解必考题型

## 答题模板

**问：** 请赏析文中画线句子。

**答：** 运用了 \_\_\_\_ 的修辞手法 / 描写方法，写了 \_\_\_\_（内容），表现了 \_\_\_\_（效果/情感）。

## 常见修辞手法及作用

| 修辞 | 作用 |
|------|------|
| 比喻 | 生动形象地写出了…… |
| 拟人 | 赋予……以人的情感，生动活泼 |
| 排比 | 增强语势，突出强调…… |
| 夸张 | 突出特征，引发联想 |
| 对比 | 突出强调了…… |

## 典型例题

**原文：** "母亲的手像松树皮一样粗糙，却为我撑起了一片天空。"

**赏析：** 运用了比喻的修辞手法，把母亲的手比作松树皮，生动形象地写出了母亲双手因操劳而粗糙不堪的样子，表现了母亲为家庭付出的艰辛，表达了作者对母亲的感激与心疼。

## 小练习

赏析："窗外的雨像断了线的珠子，噼里啪啦地砸在玻璃上。"
