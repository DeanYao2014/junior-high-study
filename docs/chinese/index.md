# 初中语文 · 部编版

## 课程体系

### 🟢 基础考点

- 字音字形、多音字形近字
- 成语辨析六大误用类型
- 名句默写、文学常识
- 病句修改

### 🟡 阅读答题模板

| 文体 | 核心考点 |
|------|----------|
| 记叙文 | 概括内容、人物形象、语句赏析、开头结尾作用、环境描写、标题含义 |
| 说明文 | 说明方法作用、语言准确性、说明顺序 |
| 议论文 | 找论点、三大论证方法作用、补充论据 |

### 🟡 文言文核心

- 古今异义、一词多义、词类活用、通假字
- 必考虚词：之 / 以 / 而 / 其 / 于

### 中考作文

- 标准三段式结构：凤头开头 + 主体细节 + 豹尾升华
- 开头结尾技巧、细节描写、意象运用

### 🔴 拔高

- 诗词鉴赏意象 + 炼字 + 表现手法
- 文章多层主旨解读
- 语言长短句赏析
