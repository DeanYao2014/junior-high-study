## 重点难点

**🔴 高频必考（占分大）**

- 因式分解（十字相乘）
- 一元二次方程：判别式 + 韦达定理 ← 全卷枢纽
- 二次函数：顶点 / 对称轴 / 最值 ← 压轴核心
- 一次函数 $k,b$ 意义 / 反比例函数 $k$ 的几何意义
- 函数—方程—不等式的数形结合

**🟡 易错 + 压轴难点**

- 含参分类讨论（方程 / 不等式 / 函数全覆盖）
- 韦达定理综合变形 + 根的分布
- 二次函数含参最值（动轴定区间）
- 绝对值与二次根式非负性陷阱 $\sqrt{a^2}=|a|$
- 分式方程增根、不等式乘除负号变号

**🟢 竞赛 / 拔高拓展定理**

均值不等式、柯西不等式、权方和、糖水不等式、绝对值三角不等式、立方和差、因式定理 / 试根法、裂项相消、双十字相乘。
