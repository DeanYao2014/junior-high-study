# 因式分解大全

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐⭐ | 十字相乘、双十字是中考/竞赛高频，拆项补项是拔高关键

## 一、五大基本方法

1. **提公因式**：$ma+mb = m(a+b)$
2. **公式法**：平方差 $a^2-b^2=(a+b)(a-b)$、完全平方 $a^2\pm2ab+b^2=(a\pm b)^2$、立方和差
3. **十字相乘**：$x^2+(p+q)x+pq=(x+p)(x+q)$；首项系数 $\ne1$ 时 $ax^2+bx+c=(a_1x+c_1)(a_2x+c_2)$
4. **分组分解**：先分组再提公因式 / 套公式
5. **拆项 / 补项（配方法）**：人为添减一项凑完全平方

## 二、拔高方法（竞赛）

1. **换元法**：整体设 $u$ 化简
2. **双十字相乘**：处理 $x^2+bxy+cy^2+dx+ey+f$
3. **试根法（因式定理）**：若 $x=p$ 使多项式为 $0$，则含因式 $(x-p)$
4. **待定系数法**：设出形式再比系数
5. **配成平方和**：证明 $A\ge0$ / 恒等

## 三、经典例题

1. 因式分解：$x^4+4$（拆项配方）
2. 因式分解：$x^4+x^2y^2+y^4$（补项）
3. 因式分解：$x^2-2xy-3y^2+2x+10y-8$（双十字）
4. 因式分解：$a^3+b^3+c^3-3abc$
5. 因式分解：$x^3-7x+6$（试根法）
6. 因式分解：$(x+1)(x+2)(x+3)(x+4)-24$（换元）
7. 因式分解：$x^2-2xy+y^2-4x+4y+3$（分组+配方）
8. 已知 $a^2+b^2+c^2=ab+bc+ca$，求证 $a=b=c$。

<details><summary>查看答案</summary>

1. $(x^2+2x+2)(x^2-2x+2)$　2. $(x^2+xy+y^2)(x^2-xy+y^2)$　3. $(x-3y+4)(x+y-2)$　4. $(a+b+c)(a^2+b^2+c^2-ab-bc-ca)$　5. $(x-1)(x+3)(x-2)$　6. $x(x+5)(x^2+5x+10)$　7. $(x-y-1)(x-y-3)$　8. 提示：移项配方成 $\dfrac12\left[(a-b)^2+(b-c)^2+(c-a)^2\right]=0$

</details>

## 四、小练习

1. 因式分解：$3x^2-6x+3 =$ ___。
2. 因式分解：$x^2-5x+6 =$ ___。
3. 因式分解：$4x^2-y^2 =$ ___。
4. 因式分解：$x^2+3x-4 =$ ___。
5. 因式分解：$a^2-b^2+4b-4 =$ ___。

<details><summary>查看答案</summary>

1. $3(x-1)^2$　2. $(x-2)(x-3)$　3. $(2x+y)(2x-y)$　4. $(x+4)(x-1)$　5. $(a+b-2)(a-b+2)$

</details>
