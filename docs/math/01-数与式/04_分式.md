# 分式

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐ | 分式方程增根、裂项相消是高频，倒数变换是拔高关键

## 一、核心概念

- **有意义**：分母 $\ne0$
- **值为 0**：分子 $=0$ 且分母 $\ne0$
- **基本性质**：$\dfrac{a}{b} = \dfrac{a\cdot m}{b\cdot m}\ (m\ne0)$
- **运算**：加减先通分，乘除约分，除以一个分式 = 乘其倒数

## 二、分式方程

- 去分母解整式方程后，必须**验根**（分母 $\ne0$），否则产生**增根**。

## 三、拓展公式（拔高）

1. **裂项相消**：$\dfrac{1}{n(n+1)} = \dfrac1n - \dfrac1{n+1}$；$\dfrac{1}{n(n+k)} = \dfrac1k\left(\dfrac1n-\dfrac1{n+k}\right)$
2. **倒数变换**：$\dfrac{x^2}{x^4+x^2+1} = \dfrac{1}{x^2+1+\frac1{x^2}}$（分子分母同除 $x^2$）
3. **比例性质**：$\dfrac ab=\dfrac cd \Rightarrow \dfrac{a+b}{a-b}=\dfrac{c+d}{c-d}$（合比/分比）

## 四、经典例题

1. 化简：$\dfrac1{x-1}-\dfrac1{x+1}-\dfrac2{x^2+1}-\dfrac4{x^4+1}$
2. 已知 $x+\dfrac1x=5$，求 $\dfrac{x^2}{x^4+x^2+1}$ 的值。
3. 已知 $\dfrac1x+\dfrac1y=2$，求 $\dfrac{3x-2xy+3y}{x+xy+y}$ 的值。
4. 若分式方程 $\dfrac2{x-2}+\dfrac{mx}{x^2-4}=\dfrac3{x+2}$ 有增根，求 $m$ 的值。
5. 计算：$\dfrac1{1\cdot2}+\dfrac1{2\cdot3}+\cdots+\dfrac1{99\cdot100}$
6. 计算：$\dfrac1{1\cdot3}+\dfrac1{3\cdot5}+\cdots+\dfrac1{2023\cdot2025}$
7. （拓展）已知 $\dfrac ab=\dfrac cd$（$a\ne b$），求证 $\dfrac{a+b}{a-b}=\dfrac{c+d}{c-d}$。
8. （竞赛）若 $\dfrac1a+\dfrac1b+\dfrac1c=\dfrac1{a+b+c}$，求证 $(a+b)(b+c)(c+a)=0$。

<details><summary>查看答案</summary>

1. $\dfrac8{x^8-1}$　2. $\dfrac1{24}$　3. $\dfrac43$　4. $m=-4$ 或 $m=6$　5. $\dfrac{99}{100}$　6. $\dfrac{1012}{2025}$　7. 设比值 $k$　8. 提示：通分移项得 $(a+b)(b+c)(c+a)=0$

</details>

## 五、小练习

1. 若分式 $\dfrac{x-1}{x+2}$ 有意义，则 $x$ 的取值范围是 ___。
2. 计算：$\dfrac2{x}+\dfrac3{x^2} =$ ___。
3. 分式方程 $\dfrac3{x-2}=\dfrac2x$ 的解是 ___。
4. 计算：$\dfrac{a^2-b^2}{a+b}\div\dfrac{a-b}{a} =$ ___。
5. 已知 $\dfrac ab=\dfrac23$，则 $\dfrac{a+b}{b} =$ ___。

<details><summary>查看答案</summary>

1. $x\ne-2$　2. $\dfrac{2x+3}{x^2}$　3. $x=-4$　4. $a$　5. $\dfrac53$

</details>
