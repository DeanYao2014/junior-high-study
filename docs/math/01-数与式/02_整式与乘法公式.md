# 整式与乘法公式

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐⭐ | 乘法公式是后续因式分解、分式、二次函数的根基，变形公式是压轴常客

## 一、幂的运算法则

| 法则 | 公式 |
|------|------|
| 同底数幂相乘 | $a^m \cdot a^n = a^{m+n}$ |
| 幂的乘方 | $(a^m)^n = a^{mn}$ |
| 积的乘方 | $(ab)^n = a^n b^n$ |
| 同底数幂相除 | $a^m \div a^n = a^{m-n}\ (a\ne0)$ |
| 零指数 / 负指数 | $a^0 = 1\ (a\ne0)$；$a^{-p} = \dfrac{1}{a^p}\ (a\ne0)$ |

## 二、乘法公式（核心）

1. **平方差**：$(a+b)(a-b) = a^2 - b^2$
2. **完全平方**：$(a\pm b)^2 = a^2 \pm 2ab + b^2$
3. **立方和差**：

$$a^3 + b^3 = (a+b)(a^2-ab+b^2),\qquad a^3 - b^3 = (a-b)(a^2+ab+b^2)$$

## 三、拓展公式（拔高必背）

1. $(a+b+c)^2 = a^2+b^2+c^2+2ab+2bc+2ca$
2. $(a\pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$
3. $a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)$
4. $a^2+b^2 = (a+b)^2-2ab = (a-b)^2+2ab$
5. $(a+b)^2-(a-b)^2 = 4ab$
6. 完全平方非负性：$a^2+b^2 \ge 2ab$（当 $a=b$ 取等）— 均值不等式雏形

## 四、经典例题

> 只给题，答案折叠（不给过程）

1. 已知 $x+\dfrac1x=3$，求 $x^2+\dfrac1{x^2}$、$x^3+\dfrac1{x^3}$、$x^4+\dfrac1{x^4}$。
2. 已知 $a+b=1$，求 $a^3+b^3+3ab$ 的值。
3. 已知 $x^2+y^2=1$，$x+y=\dfrac35$，求 $xy$ 的值。
4. 计算：$(2+1)(2^2+1)(2^4+1)(2^8+1)+1$。
5. 已知 $a-b=3$，$ab=2$，求 $a^2+b^2$、$a^3-b^3$、$a^4+b^4$。
6. （竞赛）若 $a+b+c=0$，$a^2+b^2+c^2=1$，求 $a^4+b^4+c^4$。
7. 已知 $x^2-3x+1=0$，求 $x^2+\dfrac1{x^2}$。
8. （拓展）证明：$a^3+b^3+c^3-3abc=\dfrac12(a+b+c)\left[(a-b)^2+(b-c)^2+(c-a)^2\right]$。
