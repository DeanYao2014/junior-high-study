# 二次根式

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐ | 双重根号、分母有理化是拔高常客，$\sqrt{a^2}=|a|$ 是易错陷阱

## 一、核心性质

| 性质 | 公式 |
|------|------|
| 乘法 | $\sqrt{ab}=\sqrt a\cdot\sqrt b\ (a,b\ge0)$ |
| 除法 | $\sqrt{\dfrac ab}=\dfrac{\sqrt a}{\sqrt b}\ (a\ge0,b>0)$ |
| 绝对值陷阱 | $\sqrt{a^2}=|a|$（不是 $a$） |
| 平方 | $(\sqrt a)^2 = a\ (a\ge0)$ |

**最简二次根式**：被开方数不含分母、不含开得尽的因数。
**分母有理化**：$\dfrac1{\sqrt a+\sqrt b} = \dfrac{\sqrt a-\sqrt b}{a-b}$。

## 二、拓展（拔高）

1. **双重根号**：$\sqrt{(a+b)\pm2\sqrt{ab}} = \left|\sqrt a \pm \sqrt b\right|$（找 $m+n=$ 常数项、$mn=$ 根号内乘积）
2. **分子有理化**：比较大小 / 求和常用
3. **共轭根式**：$(\sqrt a+\sqrt b)(\sqrt a-\sqrt b)=a-b$

## 三、经典例题

1. 化简：$\sqrt{4+2\sqrt3}$
2. 化简：$\sqrt{7-4\sqrt3}$
3. 计算：$\dfrac1{\sqrt2+1}+\dfrac1{\sqrt3+\sqrt2}+\cdots+\dfrac1{\sqrt{100}+\sqrt{99}}$
4. 已知 $x=\dfrac{\sqrt5+1}{2}$，求 $x-\dfrac1x$ 的值。
5. 化简：$\sqrt{x+2\sqrt{x-1}}\ (x\ge1)$
6. 已知 $a=\sqrt3+\sqrt2$，$b=\sqrt3-\sqrt2$，求 $a^2+ab+b^2$ 与 $\dfrac1a+\dfrac1b$。
7. 比较大小：$\sqrt{101}-\sqrt{100}$ 与 $\sqrt{100}-\sqrt{99}$。
8. （竞赛）求 $\sqrt{2+\sqrt{2+\sqrt{2+\cdots}}}$ 的值。

<details><summary>查看答案</summary>

1. $\sqrt3+1$　2. $2-\sqrt3$　3. $9$　4. $1$　5. $\sqrt{x-1}+1$　6. $11$；$2\sqrt3$　7. $\sqrt{101}-\sqrt{100}<\sqrt{100}-\sqrt{99}$　8. $2$

## 四、小练习

1. 化简：$\sqrt{12} =$ ___。
2. 若 $\sqrt{(a-3)^2}=3-a$，则 $a$ 的取值范围是 ___。
3. 分母有理化：$\dfrac1{\sqrt5-\sqrt3} =$ ___。
4. 计算：$\sqrt{18}-\sqrt8+\sqrt{2} =$ ___。
5. 化简：$\sqrt{9-4\sqrt5} =$ ___。

<details><summary>查看答案</summary>

1. $2\sqrt3$　2. $a\le3$　3. $\dfrac{\sqrt5+\sqrt3}{2}$　4. $2\sqrt2$　5. $\sqrt5-2$

</details>
