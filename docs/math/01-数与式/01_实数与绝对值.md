# 实数与绝对值

> 星级 ⭐⭐ ~ ⭐⭐⭐⭐ | 基础送分 + 非负性、零点分段是压轴分类讨论的根基

## 一、数的分类与数轴

**实数 = 有理数 + 无理数**

- 有理数：整数 + 分数（有限小数 / 无限循环小数）
- 无理数：无限不循环小数（如 $\sqrt2$、$\pi$）

**数轴三要素**：原点、正方向、单位长度；实数与数轴上的点**一一对应**。

- 相反数：$a$ 的相反数是 $-a$（数轴上关于原点对称）
- 倒数：$a$ 的倒数是 $\dfrac{1}{a}\ (a\ne0)$

## 二、平方根、立方根

| 概念 | 记法 | 关键性质 |
|------|------|---------|
| 平方根 | $\pm\sqrt a$ | $a\ge0$；正数有两个平方根，互为相反数 |
| 算术平方根 | $\sqrt a$ | $\sqrt a \ge 0$（**非负**） |
| 立方根 | $\sqrt[3]{a}$ | 任意实数都有，$\sqrt[3]{-a}=-\sqrt[3]{a}$ |

## 三、绝对值（重点）

**定义**

$$|a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}$$

**几何意义**：数轴上点到原点的距离 → $|a-b|$ 表示 $a$、$b$ 两点的距离。

**三大性质**

1. **非负性**：$|a| \ge 0$；若 $|a|+|b|=0$，则 $a=b=0$（平方、算术平方根同理）
2. $\sqrt{a^2}=|a|$（⚠️ 易错陷阱，不是 $a$）
3. **拓展 · 绝对值三角不等式**：$||a|-|b|| \le |a\pm b| \le |a|+|b|$

## 五、经典例题

> 先独立做，再展开核对答案（只给结果，不给过程）

1. 若 $|a-2|+(b+3)^2+\sqrt{c-1}=0$，求 $a+b+c$ 的值。
2. 化简：$\sqrt{(1-\sqrt2)^2}$。
3. 已知 $x<0$，化简 $|x|-|x-1|$。
4. 求 $|x-1|+|x-3|$ 的最小值，及此时 $x$ 的取值范围。
5. 若 $3<x<5$，化简 $\sqrt{(x-3)^2}+\sqrt{(x-5)^2}$。
6. 比较大小：$\sqrt5$ 与 $2.3$；$\sqrt3-\sqrt2$ 与 $0$。
7. 已知 $a,b$ 互为相反数，$c,d$ 互为倒数，$|m|=3$，求 $\dfrac{a+b}{m}+m^2-cd$ 的值。
8. （拓展）求 $|x+1|-|x-2|$ 的最大值。

<details><summary>查看答案</summary>

1. $0$　2. $\sqrt2-1$　3. $-1$　4. 最小值 $2$，$1\le x\le3$　5. $2$　6. $\sqrt5<2.3$；$\sqrt3-\sqrt2>0$　7. $8$　8. $3$

</details>

## 六、小练习

1. $\sqrt{16}$ 的平方根是 ___；$\sqrt[3]{-27}=$ ___。
2. 若 $\sqrt{2-x}$ 有意义，则 $x$ 的取值范围是 ___。
3. 点 $A$ 在数轴上表示 $-2$，点 $B$ 表示 $3$，则 $AB=$ ___。
4. 已知 $|a|=5,\ b^2=9$，且 $ab<0$，则 $a-b=$ ___。
5. 计算：$|\sqrt3-2|+|\sqrt3-1|=$ ___。

<details><summary>查看答案</summary>

1. $\pm2$；$-3$　2. $x\le2$　3. $5$　4. $8$ 或 $-8$　5. $1$

</details>
