# 一元二次方程

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐⭐ | 判别式 + 韦达定理是浙江中考全卷枢纽

## 一、标准形式与四种解法

**标准形式**：$ax^2+bx+c=0\ (a\ne0)$

1. **直接开平方**：$(x+m)^2=n\ (n\ge0)$
2. **配方法**：化 $(x+m)^2=n$
3. **公式法**：$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$
4. **因式分解**：化 $(x-x_1)(x-x_2)=0$

## 二、判别式

$$\Delta = b^2-4ac$$

- $\Delta>0$：两个不等实根　·　$\Delta=0$：两个相等实根　·　$\Delta<0$：无实根

## 三、韦达定理

若 $x_1,x_2$ 是 $ax^2+bx+c=0$ 的两根：

$$x_1+x_2=-\dfrac{b}{a},\qquad x_1x_2=\dfrac{c}{a}$$

## 四、韦达定理变形（拔高必背）

1. $x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2$
2. $|x_1-x_2|=\dfrac{\sqrt{\Delta}}{|a|}$
3. $\dfrac1{x_1}+\dfrac1{x_2}=\dfrac{x_1+x_2}{x_1x_2}$
4. $x_1^3+x_2^3=(x_1+x_2)^3-3x_1x_2(x_1+x_2)$
5. **根的分布**：两根同号 $\iff \Delta\ge0$ 且 $x_1x_2>0$；两根异号 $\iff x_1x_2<0$
6. **构造方程**：以 $x_1,x_2$ 为根的方程是 $x^2-(x_1+x_2)x+x_1x_2=0$

## 五、经典例题

1. 已知方程 $2x^2-5x+1=0$ 两根为 $x_1,x_2$，求 $x_1^2+x_2^2$。
2. 若方程 $x^2-6x+m=0$ 有两相等实根，求 $m$。
3. 已知 $\alpha,\beta$ 是方程 $x^2-3x-1=0$ 的两根，求 $\dfrac\alpha\beta+\dfrac\beta\alpha$。
4. 方程 $x^2-5x+m=0$ 一根是另一根的 4 倍，求 $m$。
5. 若方程 $2x^2-3x+m=0$ 有两个正根，求 $m$ 的范围。
6. 以 $2$ 和 $-3$ 为根构造一个一元二次方程。
7. 解方程 $x^2-3x+2=0$。
8. （竞赛）已知 $a,b$ 是方程 $x^2-x-1=0$ 的两根，求 $a^4+b^4$。
9. （陷阱）关于 $x$ 的方程 $x^2+(2k+1)x+k^2=0$ 两根互为相反数，求 $k$。

<details><summary>查看答案</summary>

1. $\dfrac{21}{4}$　2. $9$　3. $-11$　4. $4$　5. $0<m\le\dfrac98$　6. $x^2+x-6=0$　7. $x=1$ 或 $2$　8. $7$　9. 不存在（$k=-\dfrac12$ 时 $\Delta<0$，无实根）

## 六、小练习

1. 解方程 $x^2-5x+6=0$。
2. 方程 $x^2-4x+c=0$ 有两相等实根，则 $c=$ ___。
3. 若 $m,n$ 是方程 $x^2+x-2=0$ 的两根，则 $m+n+mn=$ ___。
4. 判断：$\Delta>0 \iff$ ___ 个不等实根。
5. 已知 $x_1,x_2$ 是方程 $x^2-4x+1=0$ 两根，则 $x_1+x_2=$ ___，$x_1x_2=$ ___。

<details><summary>查看答案</summary>

1. $x=2$ 或 $3$　2. $4$　3. $-3$　4. 2　5. $4$；$1$

</details>
