# 不等式与不等式组

> 星级 ⭐⭐⭐ ~ ⭐⭐⭐⭐⭐ | 均值、柯西、权方和是竞赛核心，含参整数解是中考高频

## 一、不等式三条基本性质

1. **传递性**：$a>b,\ b>c \Rightarrow a>c$
2. **加减**：$a>b \Rightarrow a\pm c > b\pm c$
3. **乘除**：$a>b,\ c>0 \Rightarrow ac>bc$；$a>b,\ c<0 \Rightarrow ac<bc$（⚠️ **乘除负数变号**）

## 二、一元一次不等式与不等式组

- 解一元一次不等式与解方程类似，**乘除负数时不等号反向**
- 不等式组解集口诀：**同大取大、同小取小、大小小大中间找、大大小小无处找**

## 三、经典不等式公式库（拔高核心）

**① 均值不等式（AM-GM）**

$$a^2+b^2 \ge 2ab,\qquad a+b \ge 2\sqrt{ab}\ (a,b>0),\qquad \dfrac{a+b}{2}\ge\sqrt{ab}$$

$$a+b+c \ge 3\sqrt[3]{abc}\ (a,b,c>0),\qquad a^2+b^2+c^2 \ge ab+bc+ca$$

**② 柯西不等式（Cauchy-Schwarz）**

$$(a^2+b^2)(x^2+y^2) \ge (ax+by)^2,\qquad (a+b)^2 \le 2(a^2+b^2)$$

**③ 权方和不等式（柯西分式形式）**

$$\dfrac{a^2}{x}+\dfrac{b^2}{y} \ge \dfrac{(a+b)^2}{x+y}\ (x,y>0)$$

**④ 绝对值三角不等式**

$$\bigl||a|-|b|\bigr| \le |a+b| \le |a|+|b|$$

**⑤ 糖水不等式**

$$a>b>0,\ c>0 \Rightarrow \dfrac{b}{a} < \dfrac{b+c}{a+c}$$

**⑥ 基本不等式链（调和 ≤ 几何 ≤ 算术 ≤ 平方）**

$$\dfrac{2}{\frac1a+\frac1b} \le \sqrt{ab} \le \dfrac{a+b}{2} \le \sqrt{\dfrac{a^2+b^2}{2}}$$

**⑦ 一元二次不等式（初高衔接）**

- $ax^2+bx+c>0$ 恒成立 $\iff a>0$ 且 $\Delta=b^2-4ac<0$

**⑧ 其他（竞赛）**：伯努利不等式 $(1+x)^n \ge 1+nx\ (x>-1)$；排序不等式

## 四、经典例题

1. 已知 $x>0$，求 $x+\dfrac1x$ 的最小值及等号条件。
2. 已知 $x>0,\ y>0$ 且 $x+y=4$，求 $xy$ 的最大值与 $\dfrac1x+\dfrac1y$ 的最小值。
3. 已知 $a,b>0$ 且 $\dfrac1a+\dfrac1b=1$，求 $a+b$ 的最小值。
4. 求 $|x-1|+|x-2|+\cdots+|x-10|$ 的最小值。
5. （权方和）已知 $x,y>0$ 且 $x+y=1$，求 $\dfrac1x+\dfrac4y$ 的最小值。
6. （糖水）比较 $\dfrac{2023}{2024}$ 与 $\dfrac{2024}{2025}$ 的大小。
7. 解分式不等式 $\dfrac{x-1}{x+2}<0$。
8. 解不等式组 $\begin{cases}2x-1>x+1\\x+8<4x-1\end{cases}$。
9. （含参整数解）关于 $x$ 的不等式组 $\begin{cases}x>a\\x<3\end{cases}$ 有 2 个整数解，求 $a$ 的范围。

1. 最小值 $2$，$x=1$　2. $xy\le4$（$x=y=2$）；$\ge1$　3. $4$　4. $25$　5. $9$　6. $\dfrac{2023}{2024}<\dfrac{2024}{2025}$　7. $-2<x<1$　8. $x>3$　9. $0\le a<1$

## 五、小练习

1. 解不等式：$2(x-1)>x+3$。
2. 若 $a>b$，则下列一定成立的是（　）A. $a^2>b^2$　B. $a-3>b-3$　C. $ac>bc$　D. $\dfrac ab>1$。
3. 不等式组 $\begin{cases}x>1\\x<3\end{cases}$ 的解集是 ___。
4. 已知 $x>0$，则 $x+\dfrac9x$ 的最小值是 ___。
5. 关于 $x$ 的不等式组 $\begin{cases}x-1>0\\x-a<0\end{cases}$ 有 3 个整数解，求 $a$ 的范围。

<details><summary>查看答案</summary>

1. $x>5$　2. B　3. $1<x<3$　4. $6$　5. $4<a\le5$

</details>
