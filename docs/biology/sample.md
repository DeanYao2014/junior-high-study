# 光合作用与呼吸作用

> 星级：⭐⭐⭐⭐ | 浙江中考科学常考，实验 + 计算综合

## 光合作用

**公式：**

$$\text{CO}_2 + \text{H}_2\text{O} \xrightarrow[\text{叶绿体}]{\text{光}} \text{有机物} + \text{O}_2$$

**条件：** 光、叶绿体

**实质：** 合成有机物，储存能量

## 呼吸作用

$$\text{有机物} + \text{O}_2 \rightarrow \text{CO}_2 + \text{H}_2\text{O} + \text{能量}$$

**实质：** 分解有机物，释放能量

## 对比表

| | 光合作用 | 呼吸作用 |
|---|----------|----------|
| 场所 | 叶绿体 | 线粒体 |
| 条件 | 有光 | 有光无光均可 |
| 气体 | 吸收 CO₂，释放 O₂ | 吸收 O₂，释放 CO₂ |
| 能量 | 储存能量 | 释放能量 |
