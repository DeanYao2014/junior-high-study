# 鸦片战争 · 材料分析

> 星级：⭐⭐⭐⭐ | 浙江中考材料分析必考

## 时间轴

| 时间 | 事件 |
|------|------|
| 1839 年 | 林则徐虎门销烟 |
| 1840—1842 年 | 第一次鸦片战争 |
| 1842 年 | 《南京条约》签订 |

## 《南京条约》核心内容

- 割香港岛给英国
- 开放广州、厦门、福州、宁波、上海五处通商口岸
- 赔款 2100 万银元

## 影响（四角度）

| 角度 | 内容 |
|------|------|
| 政治 | 中国开始丧失领土主权 |
| 经济 | 自然经济开始解体 |
| 社会性质 | 开始沦为半殖民地半封建社会 |
| 历史地位 | 中国近代史的开端 |

## 典型例题

**材料：** "这场战争打开了中国紧闭的大门……"

**问：** "这场战争"指什么？有何影响？

**答：** 指鸦片战争。影响：中国开始从封建社会沦为半殖民地半封建社会，是中国近代史的开端。
