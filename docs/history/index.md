# 初中历史 · 部编版

## 课程体系

### 🟢 核心框架

| 模块 | 内容 |
|------|------|
| 中国古代史 | 夏商周 → 秦汉 → 三国两晋 → 隋唐 → 宋元 → 明清 |
| 中国近代史 | 鸦片战争 → 洋务运动 → 辛亥革命 → 抗日战争 → 解放战争 |
| 中国现代史 | 建国 → 改革开放 → 新时代 |
| 世界史 | 古代文明 → 近代化 → 工业革命 → 两次世界大战 → 冷战 → 多极化 |

### 🟡 答题模板

**材料题标准四角度：** 原因 → 经过 → 影响 → 启示

**评价维度：** 政治、经济、文化、对外关系、积极意义、局限性

**人物评价：** 功绩为主 + 历史局限 + 历史地位

### 必考逻辑

- 近代史侵略与反抗
- 近代化探索（洋务/戊戌/辛亥/新文化）
- 党的发展历程
- 改革开放
- 工业革命
- 两次世界大战
- 冷战与世界格局演变
