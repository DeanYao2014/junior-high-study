# 初中学习助手

体系化备战浙江中考的在线学习教程，覆盖八门学科，深度适配浙江省专用教材：

语文（人教版）· 数学（浙教版）· 科学（浙教版）· 英语（外研版）· 历史 · 地理 · 生物 · 化学

## 特点

- **考点地图**：按浙江校考/中考高频题型组织，难度分级（⭐基础 → ⭐⭐⭐⭐拔高 → ⭐⭐⭐⭐⭐⭐竞赛）
- **边讲边练**：讲完知识点立即配例题与小练习，答案点击展开
- **动态函数图**：一次 / 反比例 / 二次函数可拖动滑块观察图像变化
- **公式渲染**：MathJax3，`$...$` 行内、`$$...$$` 块级

## 技术栈

- [VitePress](https://vitepress.dev/) + MathJax3
- 纯静态站点，GitHub Pages 部署

## 本地开发

```bash
npm install
npm run docs:dev      # 本地预览
npm run docs:build    # 构建
```
